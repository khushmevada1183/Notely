# Notely — Keyboard Shortcuts

Platform-specific keybindings for Notely (design §10.3).

| Action | Windows / Linux | macOS |
|--------|-----------------|-------|
| New File | `Ctrl+N` | `Cmd+N` |
| Open File | `Ctrl+O` | `Cmd+O` |
| Save | `Ctrl+S` | `Cmd+S` |
| Save As | `Ctrl+Shift+S` | `Cmd+Shift+S` |
| Find | `Ctrl+F` | `Cmd+F` |
| Replace | `Ctrl+H` | `Cmd+Alt+F` |
| Undo | `Ctrl+Z` | `Cmd+Z` |
| Redo | `Ctrl+Y` | `Cmd+Shift+Z` |
| Cut | `Ctrl+X` | `Cmd+X` |
| Copy | `Ctrl+C` | `Cmd+C` |
| Paste | `Ctrl+V` | `Cmd+V` |
| Select All | `Ctrl+A` | `Cmd+A` |
| Close Window | `Ctrl+W` | `Cmd+W` |
| Quit | `Alt+F4` | `Cmd+Q` |

## Notes

- **File** and **Edit** menu items show the correct accelerator for your platform.
- Find and Replace shortcuts are handled inside the Monaco editor when it has focus.
- Word wrap, line numbers, and theme selection are available from the **View** menu only (no default keyboard shortcuts).
- Custom keybindings are not supported in v1.0.
